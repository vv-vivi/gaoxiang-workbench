# 高项占分比备考台

信息系统项目管理师（软考高项）备考工作台，**以考试考点占分比为主线**（非教材章节顺序）整理。

## 在线使用

- GitHub Pages：开启 Pages 后访问 `https://vv-vivi.github.io/gaoxiang-workbench/`
- 手机/微信：建议「在浏览器打开 → 添加到主屏幕」，打卡数据存本地 localStorage；换设备用「导出 JSON 备份」迁移

## 考情依据（2026 检索）

- 考试时间：2027-05-22/23（预计），一年仅上半年 1 次，机考，三科各 75 分 / 45 分合格，无成绩滚动
- 综合知识 75 分分布：十大管理约 30 分、高级知识 8-12 分、信息技术与信息化 6-8 分、信息系统工程 4 分、概论与立项 4-6 分、法规标准 3-5 分、管理科学 3-5 分、英语固定 5 分、时政 2-3 分
- 案例分析 75 分：简答约 50 分 + 计算约 25 分（挣值/关键路径必考）
- 论文 75 分：十大领域选一题，2500 字内，需真实项目素材

## 功能（4 个模块）

1. **今日**：当前阶段任务勾选、按分值权重轮转的每日背诵打卡、连续天数统计
2. **分值**：综合知识考点分值脑图（SVG）、分值排行、每模块完整背诵要点
3. **计划**：占分倒排五阶段（基础精读 → 计算强化 → 案例实战 → 论文写作 → 冲刺背诵）+ 报名/准考证关键节点
4. **我的**：考试信息卡、导出/导入 JSON 备份、清空数据

单文件 HTML，零外部依赖，离线可用。
